1. Нужно выделить интерфейс и логику МИС в отдельный микросервис. Это позволит обеспечить надёжность и масштабируемость системы, позволит исключить лишнюю логику из DWH.
2. Нужно разделить существующее хранилище данных на разные БД:
- БД Медицинской информационной системы - БД необходимая для обеспечения текущей работы системы. Хранит минимально необходимый набор персональных данных. 
- БД данных с медицинской информацией - хранит медицинские карты, снимки, анализы и т.д.
- БД c финансовой информацией 
3. Данные из DWH на MSSQL Server необходимо выгрузить в хранилища из предыдущего пункта. В качестве СУБД для новых хранилищ можно использовать Postgresql и Handoop. После миграции данных вывести MSSQL Server из эксплуатации.
4. В качестве аналитических БД использовать Clickhouse
5. Для каталогизации данных по доменам использовать DataHub
4. Опционально заменить Power BI на Opensource решение совместимое с ClickHouse (Yandex DataLens). В задании не сказано, но вероятно внедрение Power BI было связано со стеком Microsoft (DWH на MS SQL, Power BI). PowerBI можно настроить на взаимодейстиве с ClickHouse при помощи коннектора.
5. В качестве "витрины данных/портала самообслуживания" наиболее подходит Yandex DataLens (совместим с ClickHouse, позволяет строить красивые графики и диаграммы).
